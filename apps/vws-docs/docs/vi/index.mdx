**ventiws** là một bản triển khai WebSocket cho Node.js với API của [`ws`](https://github.com/websockets/ws), được cung cấp dưới dạng native addon với bộ máy đóng khung viết bằng [Zig](https://ziglang.org). Nó nhắm tới `ws` 8.22.0 và tái tạo hành vi quan sát được của bản phát hành đó thay vì mã nguồn. ventiws không liên kết với dự án `ws` và không nhúng mã nguồn nào của dự án đó.

## Điểm nổi bật [#highlights]

- **API `ws`** — `WebSocket` và `WebSocketServer`, với giá trị mặc định của tùy chọn khớp `ws`: `maxPayload` 100 MiB, `maxFragments` 16384 và `closeTimeout` 30000 ms.
- **Native addon** — bộ máy đóng khung viết bằng Zig; các constructor là hàm thuần trả về bản ghi trạng thái, không `class`, không `this`, không prototype.
- **Không cần compiler khi cài** — các gói binding theo nền tảng giúp `pnpm add ventiws` không cần toolchain.
- **Khả năng tương thích có thể kiểm chứng** — mọi mục bề mặt của `ws`, trạng thái và bài kiểm thử bằng chứng đều được theo dõi trong ma trận tương thích của kho.
- **Dev logger** — các bản ghi vòng đời được in ngay khi xảy ra (splash, open, close, error) mà không cần đăng ký callback.

## Echo server và client [#echo-server-and-client]

```ts
import { WebSocket, WebSocketServer } from "ventiws";

const server = new WebSocketServer({ port: 8080 });

server.on("connection", (socket) => {
  socket.on("message", (data, isBinary) => {
    socket.send(isBinary ? data : `echo: ${data.toString()}`);
  });
});

const client = new WebSocket("ws://127.0.0.1:8080/");
client.on("open", () => client.send("hello"));
client.on("message", (data) => console.log("client saw", data.toString()));
```

:::warning
ventiws đang ở giai đoạn trước 1.0: bề mặt API có thể thay đổi giữa các bản beta, và Windows chưa được hỗ trợ. Ma trận tương thích và các khác biệt đã biết so với `ws` nằm trong [kho](https://github.com/farbenbuilds/ventiws).
:::
