    <div class="docs-home-section-intro">
      <h2 id="server-heading">{"Use µWZ as your server"}</h2>
      <p>
        {
          "Keep the Zig application you already have. The runtime takes over transport, TLS, limits, and shutdown without changing how your handlers are written."
        }
      </p>
    </div>
  </div>
  <ol class="docs-home-steps" role="list">
    <li class="docs-home-step">
      <span class="docs-home-step-number" aria-hidden="true">
        {"01"}
      </span>
      <h3>{"Add the package"}</h3>
      <p>
        {
          "Fetch the pinned dependencies through the Zig package manager. No CMake, Ninja, Go, Perl, Python, or system zlib."
        }
      </p>
    </li>
    <li class="docs-home-step">
      <span class="docs-home-step-number" aria-hidden="true">
        {"02"}
      </span>
      <h3>{"Mount your handlers"}</h3>
      <p>
        {
          "Register HTTP, WebSocket, RPC, and static routes on one app. Your handlers stay ordinary Zig functions."
        }
      </p>
    </li>
    <li class="docs-home-step">
      <span class="docs-home-step-number" aria-hidden="true">
        {"03"}
      </span>
      <h3>{"Run where you deploy"}</h3>
      <p>
        {
          "Start one process or a thread-per-core cluster. Each worker owns its event loop, slab set, and physical core affinity where the platform allows."
        }
      </p>
    </li>
  </ol>
