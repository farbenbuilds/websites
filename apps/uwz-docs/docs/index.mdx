<section class="docs-home-section" aria-labelledby="highlights">
  <h2 class="editorial-label" id="highlights">
    {"Highlights"}
  </h2>
  <ul class="docs-home-facts" role="list">
    <li>
      <strong>Data-oriented.</strong> Struct-of-arrays pools, parallel router arrays, and
      compile-time capacities make exhaustion explicit.
    </li>
    <li>
      <strong>Readable types.</strong> Named callback, event, and override types instead of inline
      anonymous structs.
    </li>
    <li>
      <strong>Cross-platform.</strong> Linux and macOS on x86_64 and aarch64 are supported and
      tested; Windows is compile-checked only.
    </li>
  </ul>
</section>

  <section class="docs-home-section" aria-labelledby="a-complete-server">
    <p class="editorial-label">Example</p>
    <h2 id="a-complete-server">A complete server</h2>

    ```zig
    const std = @import("std");
    const uz = @import("uWebZockets");

    fn hello(_: *uz.Request, res: *uz.Response) void {
        res.text("hello from uWebZockets") catch {};
    }

    pub fn main(init: std.process.Init) !void {
        var app = try uz.App(128).init(init.io);
        defer app.deinit();

        _ = try app.get("/", hello);
        try app.listen("0.0.0.0", 3000);
        try app.run();
    }
    ```

    The same module carries the rest of the battery: `app.ws(...)` for WebSocket,
    `app.rpc(...)` for JSON-RPC, `app.static(...)` for assets, `build_cluster`
    for thread-per-core workers, `init_https_ephemeral` for HTTPS with no
    certificate files, and `listen_udp` plus `init_http3` for HTTP/3.

  </section>
