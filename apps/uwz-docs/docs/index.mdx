<section class="docs-home-section" id="support" aria-labelledby="support-heading">
  <div class="docs-home-section-head">
    <p class="editorial-label">{"02 / Support"}</p>
    <div class="docs-home-section-intro">
      <h2 id="support-heading">{"What µWZ supports"}</h2>
      <p>
        {
          "One server surface for the transports a Zig service actually needs, with the same routing, limits, and lifecycle across each one."
        }
      </p>
    </div>
  </div>
  <ol class="docs-home-support-grid" role="list">
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"01"}
      </span>
      <div>
        <h3>{"HTTP/1.1 and HTTP/2"}</h3>
        <p>
          {
            "Persistent connections, streaming bodies, multiplexed streams, and TLS ALPN in one handler model."
          }
        </p>
      </div>
    </li>
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"02"}
      </span>
      <div>
        <h3>{"HTTP/3"}</h3>
        <p>
          {
            "QUIC over UDP with the same routing and handlers as the TCP transports. QUIC clustering is not supported."
          }
        </p>
      </div>
    </li>
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"03"}
      </span>
      <div>
        <h3>{"WebSocket"}</h3>
        <p>{"RFC 6455 with compression, pub/sub, and heartbeats for long-lived connections."}</p>
      </div>
    </li>
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"04"}
      </span>
      <div>
        <h3>{"RPC"}</h3>
        <p>{"Typed request and response calls that share the app, limits, and worker model."}</p>
      </div>
    </li>
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"05"}
      </span>
      <div>
        <h3>{"TLS"}</h3>
        <p>Ephemeral and production credentials, ALPN, 0-RTT, and mutual TLS.</p>
      </div>
    </li>
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"06"}
      </span>
      <div>
        <h3>{"Static assets"}</h3>
        <p>{"Serve files from the same process instead of adding a second asset server."}</p>
      </div>
    </li>
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"07"}
      </span>
      <div>
        <h3>{"Thread-per-core workers"}</h3>
        <p>
          {
            "Shared-nothing workers with one event loop each, pinned to physical cores where the platform allows."
          }
        </p>
      </div>
    </li>
    <li class="docs-home-support-item">
      <span class="docs-home-support-number" aria-hidden="true">
        {"08"}
      </span>
      <div>
        <h3>{"Zero allocation"}</h3>
        <p>{"Bounded startup slabs and explicit capacity limits on every request path."}</p>
      </div>
    </li>
  </ol>

<section class="docs-home-section" id="server" aria-labelledby="server-heading">
  <div class="docs-home-section-head">
    <p class="editorial-label">{"03 / Server"}</p>
    <div class="docs-home-section-intro">
      <h2 id="server-heading">{"Use µWZ as your server"}</h2>
      <p>
        {
          "Keep the Zig application you already have. The runtime takes over transport, TLS, limits, and shutdown without changing how your handlers are written."
        }
      </p>
    </div>
  </div>
  <ol class="docs-home-steps" role="list">
    <li class="docs-home-step">
      <span class="docs-home-step-number" aria-hidden="true">
        {"01"}
      </span>
      <h3>{"Add the package"}</h3>
      <p>
        {
          "Fetch the pinned dependencies through the Zig package manager. No CMake, Ninja, Go, Perl, Python, or system zlib."
        }
      </p>
    </li>
    <li class="docs-home-step">
      <span class="docs-home-step-number" aria-hidden="true">
        {"02"}
      </span>
      <h3>{"Mount your handlers"}</h3>
      <p>
        {
          "Register HTTP, WebSocket, RPC, and static routes on one app. Your handlers stay ordinary Zig functions."
        }
      </p>
    </li>
    <li class="docs-home-step">
      <span class="docs-home-step-number" aria-hidden="true">
        {"03"}
      </span>
      <h3>{"Run where you deploy"}</h3>
      <p>
        {
          "Start one process or a thread-per-core cluster. Each worker owns its event loop, slab set, and physical core affinity where the platform allows."
        }
      </p>
    </li>
  </ol>
  <div class="docs-home-server-cta">
    <p>{"Bring your routes. The runtime owns transport, TLS, limits, and shutdown."}</p>
