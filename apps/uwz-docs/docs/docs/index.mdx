µWebZockets 2.1.6 is a zero-allocation, shared-nothing server framework for Zig
0.16.0. One `Request` and `Response` API serves HTTP/1.1, HTTP/2, HTTP/3,
WebSocket, and JSON-RPC from bounded slabs that are allocated once at startup.

This site is the task-oriented entry point. Each page states the behavior,
limits, and unsupported features it documents.

## Feature coverage [#feature-coverage]

The table is the site's launch feature matrix. The full boundary list,
including helper-only and experimental modules, is in the repository roadmap.

| Surface                  | Status             | Start with                                                           |
| ------------------------ | ------------------ | -------------------------------------------------------------------- |
| HTTP/1.1 request routing | Supported          | [Your first HTTP server](/docs/examples/first-http-server)           |
| HTTP/2 request routing   | Supported, bounded | [HTTP/2](/docs/http2)                                                |
| WebSocket server         | Supported          | [WebSocket](/docs/websocket)                                         |
| JSON-RPC 2.0             | Supported          | [Your first JSON-RPC service](/docs/examples/first-json-rpc-service) |
| TLS 1.3 termination      | Supported          | [Your first TLS server](/docs/examples/first-tls-server)             |
| Thread-per-core cluster  | Supported on TCP   | [Your first cluster](/docs/examples/first-cluster)                   |
| HTTP/3 request routing   | Supported          | [HTTP/3 and QUIC](/docs/http3)                                       |
| HTTP/3 clustering        | Not supported      | [HTTP/3 limits](/docs/http3/limits)                                  |
| WebTransport live path   | Not supported      | [WebTransport status](/docs/http3/webtransport)                      |
| WebSocket client         | Not supported      | [WebSocket](/docs/websocket)                                         |

[Read the full roadmap and boundaries](https://github.com/farbenbuilds/uWebZockets/blob/main/docs/roadmap.md)
