µWebZockets 2.1.6 is a zero-allocation, shared-nothing server framework for Zig
0.16.0. One `Request` and `Response` API serves HTTP/1.1, HTTP/2, HTTP/3,
WebSocket, and JSON-RPC from bounded slabs that are allocated once at startup.

This site is the task-oriented entry point. The repository remains the source of
truth for wire behavior, limits, and release evidence.

## Helpers

Small composable utilities live in the HTTP helper layer. Query and form
parsing, multipart parsing, cookies, compression, ETag and conditional GET,
`Accept` negotiation, fetch and stream primitives, and WebSocket stream adapters
are documented in the repository until the Helpers hub ships on this site.

[Read the request and response helpers](https://github.com/farbenbuilds/uWebZockets/blob/main/docs/http.md#request-and-response-helpers)

helper-only and experimental modules, is in the repository roadmap.
