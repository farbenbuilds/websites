The repository ships runnable examples for each supported surface. Every step
accepts `-Doptimize=ReleaseSafe` for a production-shaped build.

```sh
zig build -Doptimize=ReleaseSafe
```

The default install writes the example binaries to `zig-out/bin`. The table maps
each step to its behavior, source file, and the related site page.

| Step                           | Shows                                                           | Source                                                                                                            | Site page                                                         |

## Compliance targets

These targets are for repository verification, not application onboarding:

| Step                           | Purpose                                  |
| ------------------------------ | ---------------------------------------- |
| `zig build h1spec`             | HTTP/1.1 conformance suite on port 8000. |
| `zig build autobahn`           | RFC 6455 compliance target on port 9001. |
| `zig build test --summary all` | Unit, C ABI, and protocol tests.         |
| `zig build fuzz --fuzz=100K`   | Deterministic protocol fuzzing.          |

## Run one example

```sh
zig build hello_world -Doptimize=ReleaseSafe
./zig-out/bin/hello_world
```

In another terminal:

```sh
curl -i http://127.0.0.1:3000/
```

The response is `HTTP/1.1 200 OK` with the body from
`examples/hello_world.zig`. Use the same pattern for every step: build the
step, run the binary, and send the request shown on its site page.

## Ports at a glance

| Port |        Protocol | Examples                                                                                   |
| ---- | --------------: | ------------------------------------------------------------------------------------------ |
| 3000 |        HTTP/1.1 | `hello_world`, `chat_server`, `rpc_server`, `shared_nothing_cluster`, `basic_microservice` |
| 3001 |        HTTP/1.1 | `custom_builder`                                                                           |
| 3443 |           HTTPS | `https_server`                                                                             |
| 8000 |        HTTP/1.1 | `h1spec`                                                                                   |
| 8443 | HTTPS or HTTP/3 | `tls_cluster`, `http3_server`                                                              |
| 9001 |       WebSocket | `autobahn_server`                                                                          |

Only one process can bind a port at a time. Stop the previous example before
starting another one on the same port.
