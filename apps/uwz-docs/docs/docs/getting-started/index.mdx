This section takes you from a clean machine to a running server. It covers
installation, the first project, the application model, and the answers readers
need before adding protocol routes.

## Before you begin

You need:

- Zig 0.16.0 from [ziglang.org/download](https://ziglang.org/download/). Check
  with `zig version`.
- A Linux or macOS host on `x86_64` or `aarch64`. Windows has compile and
  runtime jobs, but official runtime support follows a green release job.
- `curl` for the HTTP examples.

## Conventions used in these tutorials

Every Zig example declares a complete `main` and imports `uWebZockets`. The
examples use `std.process.Init` and `init.io` because Zig 0.16 passes the I/O
implementation through `main`.

Error handling is explicit. A handler that cannot recover logs the error or
returns a status; a tutorial does not hide a failure with `catch {}` unless the
callback signature cannot return an error and the page explains why.

Commands use a `sh` fence; expected output uses `text` or `console`. Commands
assume the project root unless a step says otherwise.
