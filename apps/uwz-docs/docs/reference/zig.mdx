`src/root.zig` defines the supported Zig surface. This page lists all 79 public
exports, groups them by area, and sends each one to the page that explains its
task. A name that is absent here is not part of the supported surface, even when
the module that owns it is importable from the repository.

## How to use this index [#how-to-use-this-index]

| You need                        | Read                           | Then open                                        |
| ------------------------------- | ------------------------------ | ------------------------------------------------ |
| A constructor or a value        | The export row                 | The primary page column                          |
| A helper module                 | The module row                 | The concept or guide page for that module        |
| A stable link to one export     | The `<a id="Name"></a>` anchor | `/reference/zig#Name`                            |
| The wire behavior behind a name | The primary page               | [Limits](/reference/limits) or the protocol page |

The kind column uses four values: `type` is a struct, enum, union, or
function-pointer type; `function` is a comptime type constructor; `module` is a
public import with its own functions and types; `value` is a constant.

## Drift check [#drift-check]

`src/root.zig` is the only source of truth for this page. It declares 79
`pub const` names, and every one appears exactly once above. Several modules
expose additional public declarations inside their own files; those are reached
through the module row, not through a second root export. `src/root.zig` also
analyzes `src/c_api.zig` in a `comptime` block so the `uwz_*` symbols reach the
static library, but the C ABI is a separate surface documented in
[C ABI](/reference/c-abi).

When a release adds, renames, or removes a root export, update this table in the
same change. A table row without a matching `pub const`, or a `pub const` without
a row, is documentation drift.
