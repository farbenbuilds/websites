Use this page to identify a Zig error, a JSON-RPC fault, a WebSocket rejection,
or a C ABI code. [Errors and failure modes](/docs/concepts/errors) explains the
two reporting channels; [HTTP errors](/docs/http/errors) covers response
documents. The tables below own the name-to-cause lookup.

## How to read an error [#how-to-read-an-error]

A Zig error is a value in an error union. It carries a stable name, not a
formatted message, and `@errorName` returns that name. Startup and registration
errors happen before a request exists, so they have no HTTP status. Request-time
errors either become a response status, a WebSocket close code, or a transport
abort chosen by the code that catches them.

```zig
const std = @import("std");
const uz = @import("uWebZockets");

fn hello(_: *uz.Request, res: *uz.Response) void {
    res.text("ok") catch |err| {
        std.debug.print("response: {s}\n", .{@errorName(err)});
    };
}

pub fn main(init: std.process.Init) !void {
    var app = try uz.App(128).init(init.io);
    defer app.deinit();

    _ = app.get("/", hello) catch |err| {
        std.debug.print("route registration: {s}\n", .{@errorName(err)});
        return err;
    };
    try app.listen("0.0.0.0", 3000);
    try app.run();
}
```

| Form                         | Meaning                                          |
| ---------------------------- | ------------------------------------------------ |
| `error.RouteCapacityReached` | The Zig error tag returned by a call             |
| `@errorName(err)`            | The tag as a string, suitable for logs and tests |
| `uwz_error_name(code)`       | The static C ABI name, including `unknown error` |
| `4xx` or `5xx`               | A peer-facing status, not an error tag           |

Match on the error value with `switch`; do not parse a log line or a status
string to recover the name. A terminal error needs a configuration or code
change, not a retry loop.

## Route registration [#route-registration]

These errors occur while registering routes, middleware, WebSocket handlers, or
static mounts. The default capacities are `256` nodes, `64` pattern routes, `32`
middleware callbacks, `2 KiB` per path, and `64 KiB` for the route registry.

| Zig error name                        | Cause                                                                                                                                                                                                   | HTTP status        | Fix                                                                                                    | Source module                                        |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| `error.InvalidRoutePath`              | Empty, not rooted at `/`, longer than `max_route_path_size`, or contains `?`, `#`, CR, or LF. A static mount prefix also rejects `:` and `*`                                                            | None, registration | Use a rooted literal path without query, fragment, or control bytes                                    | `src/router/radix_pattern.zig`, `src/router/app.zig` |
| `error.InvalidRoutePattern`           | A capture name is empty or outside `[A-Za-z0-9_-]`, a wildcard is not the final segment, or two captures share a name                                                                                   | None, registration | Name each capture once and end with `*` only at the path tail                                          | `src/router/radix_pattern.zig`                       |
| `error.RouteCapacityReached`          | No radix node, pattern slot, or route record remains                                                                                                                                                    | None, registration | Simplify shared prefixes, or raise `max_route_nodes` and `max_pattern_routes`                          | `src/router/radix.zig`                               |
| `error.RouteStorageCapacityReached`   | The retained route paths exceed `max_route_registry_size`, `64 KiB` by default                                                                                                                          | None, registration | Raise `max_route_registry_size`, or shorten paths                                                      | `src/router/radix.zig`                               |
| `error.RouteParameterCapacityReached` | A pattern needs more captures than `max_route_params`, `16` by default                                                                                                                                  | None, registration | Raise `max_route_params`, or flatten the pattern                                                       | `src/router/radix_pattern.zig`                       |
| `error.RoutePatternConflicts`         | Two patterns have the same shape but different capture names, such as `/users/:id` and `/users/:name`                                                                                                   | None, registration | Keep one capture spelling for one route shape                                                          | `src/router/radix.zig`                               |
| `error.RouteAlreadyRegistered`        | The same method and path are registered twice                                                                                                                                                           | None, registration | Remove the duplicate, or register a different method                                                   | `src/router/radix.zig`                               |
| `error.MiddlewareCapacityReached`     | More than `max_middleware`, `32` by default, callbacks are registered                                                                                                                                   | None, registration | Raise `max_middleware`, or combine middleware                                                          | `src/router/radix.zig`                               |
| `error.StaticRouteCapacityReached`    | More than eight `app.static` mounts are registered                                                                                                                                                      | None, registration | Serve several trees from one mount, or raise the fixed limit in source                                 | `src/router/app.zig`                                 |
| `error.RoutesLocked`                  | A route or middleware registration follows a successful `listen`, `listen_all`, or `listen_udp`                                                                                                         | None, registration | Register every route before the first listener call                                                    | `src/router/app.zig`                                 |
| `error.InvalidWebSocketLimits`        | A frame or message bound is `0`, frame size exceeds message size, one heartbeat timeout is set without the other, a timeout exceeds `i64`, or the message bound exceeds the configured WebSocket buffer | None, registration | Set a nonzero frame and message bound, keep frame at or below message, and pair the heartbeat timeouts | `src/router/app.zig`                                 |

`app.datagram` and `app.datagram_context` use a separate 16-path table in
`src/router/datagram.zig`. They reuse the names `error.RouteCapacityReached` and
`error.RouteAlreadyRegistered`, and also return `error.InvalidPath` for a
non-rooted path.

## JSON-RPC [#json-rpc]

A handler error becomes a JSON-RPC error object; the HTTP status stays `200`
unless dispatch itself fails. The standard codes are `-32700` parse error,
`-32600` invalid request, `-32601` method not found, `-32602` invalid params,
and `-32603` internal error.

| Zig error name                       | Cause                                                                     | HTTP status                                                                         | Fix                                                       | Source module          |
| ------------------------------------ | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------- | ---------------------- |
| `error.Aborted`                      | The abort signal fired because the request, timeout, or socket is gone    | `500` only while the transport is still writable; no response when the peer is gone | Stop work and do not write a result                       | `src/rpc/json_rpc.zig` |
| `error.ApplicationError`             | The handler returned `Call.fail(code, message)`                           | `200` with the application fault code                                               | Use a stable application code and a short message         | `src/rpc/json_rpc.zig` |
| `error.InternalError`                | The handler returned `error.InternalError`                                | `200`, JSON-RPC `-32603`                                                            | Fix the procedure or return a typed application fault     | `src/rpc/json_rpc.zig` |
| `error.InvalidParams`                | Parameters are absent, or the JSON does not match the typed shape         | `200`, JSON-RPC `-32602`                                                            | Validate the client payload and keep the Zig type aligned | `src/rpc/json_rpc.zig` |
| `error.OutOfMemory`                  | The parameter allocator failed                                            | `200`, JSON-RPC `-32603`                                                            | Reduce the parameter size, or use fixed storage           | `src/rpc/json_rpc.zig` |
| `error.ResultAlreadyWritten`         | `Call.result` runs more than once                                         | `200`, JSON-RPC `-32603`                                                            | Return exactly one result                                 | `src/rpc/json_rpc.zig` |
| `error.ResultTooLarge`               | The encoded result does not fit the service response buffer               | `200`, JSON-RPC `-32603`                                                            | Raise `response_capacity`, or return fewer bytes          | `src/rpc/json_rpc.zig` |
| `error.ResponseTooLarge`             | The dispatch document does not fit the response buffer                    | `500` from `rpc.http`                                                               | Raise the service response capacity                       | `src/rpc/json_rpc.zig` |
| `error.DuplicateProcedure`           | Two procedures share a method name                                        | None, registration                                                                  | Register each method once                                 | `src/rpc/json_rpc.zig` |
| `error.InvalidMethodName`            | The name is empty, over `255` bytes, invalid UTF-8, or starts with `rpc.` | None, registration                                                                  | Use a shorter valid name without the reserved prefix      | `src/rpc/json_rpc.zig` |
| `error.MethodStorageCapacityReached` | Method names exceed the `4 KiB` storage                                   | None, registration                                                                  | Shorten names, or raise `method_storage_capacity`         | `src/rpc/json_rpc.zig` |

## WebSocket handshake [#websocket-handshake]

The HTTP/1.1 upgrade maps handshake validation to `400 Bad Request` or
`426 Upgrade Required`. A route `upgrade` callback that returns `false` sends
`403 Forbidden` without setting an error name.

| Zig error name                   | Cause                                               | HTTP status | Fix                                        | Source module          |
| -------------------------------- | --------------------------------------------------- | ----------- | ------------------------------------------ | ---------------------- |
| `error.InvalidMethod`            | The upgrade request is not `GET`                    | `400`       | Send a `GET` upgrade request               | `src/ws/handshake.zig` |
| `error.MissingConnectionUpgrade` | `Connection` is absent or lacks the `upgrade` token | `400`       | Send `Connection: Upgrade`                 | `src/ws/handshake.zig` |
| `error.MissingUpgradeWebSocket`  | `Upgrade` is absent or is not `websocket`           | `400`       | Send `Upgrade: websocket`                  | `src/ws/handshake.zig` |
| `error.MissingVersion`           | `Sec-WebSocket-Version` is absent or duplicated     | `426`       | Send one `Sec-WebSocket-Version: 13` field | `src/ws/handshake.zig` |
| `error.UnsupportedVersion`       | The version is not `13`                             | `426`       | Use RFC 6455 version `13`                  | `src/ws/handshake.zig` |
| `error.MissingKey`               | `Sec-WebSocket-Key` is absent or duplicated         | `400`       | Send one key field                         | `src/ws/handshake.zig` |
| `error.InvalidKey`               | The key is not canonical base64 for 16 bytes        | `400`       | Send a fresh 16-byte base64 key            | `src/ws/handshake.zig` |

`handshake.validate_extended_connect` reuses `error.MissingVersion` and
`error.UnsupportedVersion` for RFC 8441. The caller chooses the rejection; the
helper does not write a response.

## C ABI codes [#c-abi-codes]

The negative values are append-only and part of the ABI.
[`uwz_error_name`](/reference/c-abi#uwz_error) returns a static string for each
code, and `unknown error` outside the enum.

|  Code | Constant                     | Name string        | Reported when                                                               |
| ----: | ---------------------------- | ------------------ | --------------------------------------------------------------------------- |
|   `0` | `UWZ_OK`                     | `ok`               | The call completed                                                          |
|  `-1` | `UWZ_ERROR_INVALID_ARGUMENT` | `invalid argument` | Bad slice, occupied out-handle, invalid route, invalid method or limits     |
|  `-2` | `UWZ_ERROR_OUT_OF_MEMORY`    | `out of memory`    | Slab, TLS context, or QUIC engine allocation failed                         |
|  `-3` | `UWZ_ERROR_INVALID_STATE`    | `invalid state`    | Wrong lifecycle step, started response, stale token, HTTP/3 not initialized |
|  `-4` | `UWZ_ERROR_ALREADY_EXISTS`   | `already exists`   | Duplicate route pattern or bound listener                                   |
|  `-5` | `UWZ_ERROR_CAPACITY`         | `capacity reached` | Route, middleware, parameter, storage, or peer capacity reached             |
|  `-6` | `UWZ_ERROR_WOULD_BLOCK`      | `would block`      | Output queue or write path is full                                          |
|  `-7` | `UWZ_ERROR_PROTOCOL`         | `protocol error`   | Framing, handshake, or oversized output                                     |
|  `-8` | `UWZ_ERROR_IO`               | `I/O error`        | Socket, bind, or TLS read and write failure                                 |
|  `-9` | `UWZ_ERROR_UNSUPPORTED`      | `unsupported`      | HTTP/3 unavailable, or the backend is unavailable                           |
| `-10` | `UWZ_ERROR_INTERNAL`         | `internal error`   | A failure with no narrower mapping                                          |
