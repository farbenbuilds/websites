**µWebZockets** là framework máy chủ cho [Zig 0.16.0](https://ziglang.org), phục vụ HTTP/1.1, HTTP/2, HTTP/3, WebSocket và JSON-RPC qua một API `Request`/`Response` type-safe duy nhất. Các yêu cầu được phân tích, định tuyến và phản hồi từ những slab có giới hạn, được cấp phát một lần khi khởi động, mỗi luồng sở hữu một slab riêng và tái sử dụng mà không cần khóa.

## Điểm nổi bật [#highlights]

- **Zero allocation** — không có đường xử lý yêu cầu, phân tích, định tuyến hay ghi nào cấp phát bộ nhớ.
- **Shared-nothing** — mỗi worker chạy event loop, bộ slab và lõi vật lý được ghim riêng, chỉ phối hợp qua các ring không khóa.
- **Định hướng dữ liệu** — pool struct-of-arrays, mảng router song song và dung lượng xác định lúc biên dịch, khiến việc cạn tài nguyên trở nên tường minh.
- **Kiểu dễ đọc** — các kiểu callback, event và override có tên thay cho struct ẩn danh nội tuyến.
- **Đa nền tảng** — hỗ trợ và kiểm thử trên Linux và macOS x86_64/aarch64; Windows mới chỉ được kiểm tra biên dịch.

## Một máy chủ hoàn chỉnh [#a-complete-server]

```zig
const std = @import("std");
const uz = @import("uWebZockets");

fn hello(_: *uz.Request, res: *uz.Response) void {
    res.text("hello from uWebZockets") catch {};
}

pub fn main(init: std.process.Init) !void {
    var app = try uz.App(128).init(init.io);
    defer app.deinit();

    _ = try app.get("/", hello);
    try app.listen("0.0.0.0", 3000);
    try app.run();
}
```

Cùng một module mang phần còn lại của bộ công cụ: `app.ws(...)` cho WebSocket, `app.rpc(...)` cho JSON-RPC, `app.static(...)` cho tài nguyên tĩnh, `build_cluster` cho worker thread-per-core, `init_https_ephemeral` cho HTTPS không cần tệp chứng chỉ, cùng `listen_udp` và `init_http3` cho HTTP/3.
