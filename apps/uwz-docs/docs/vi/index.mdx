<section class="docs-home-section" aria-labelledby="highlights">
  <h2 class="editorial-label" id="highlights">
    {"Điểm nổi bật"}
  </h2>
  <ul class="docs-home-facts" role="list">
    <li>
      <strong>Định hướng dữ liệu.</strong> Pool struct-of-arrays, mảng router song song và dung
      lượng xác định lúc biên dịch khiến việc cạn tài nguyên trở nên tường minh.
    </li>
    <li>
      <strong>Kiểu dễ đọc.</strong> Các kiểu callback, event và override có tên thay cho struct ẩn
      danh nội tuyến.
    </li>
    <li>
      <strong>Đa nền tảng.</strong> Hỗ trợ và kiểm thử trên Linux và macOS x86_64/aarch64; Windows
      mới chỉ được kiểm tra biên dịch.
    </li>
  </ul>
</section>

  <section class="docs-home-section" aria-labelledby="a-complete-server">
    <p class="editorial-label">Ví dụ</p>
    <h2 id="a-complete-server">Một máy chủ hoàn chỉnh</h2>

    ```zig
    const std = @import("std");
    const uz = @import("uWebZockets");

    fn hello(_: *uz.Request, res: *uz.Response) void {
        res.text("hello from uWebZockets") catch {};
    }

    pub fn main(init: std.process.Init) !void {
        var app = try uz.App(128).init(init.io);
        defer app.deinit();

        _ = try app.get("/", hello);
        try app.listen("0.0.0.0", 3000);
        try app.run();
    }
    ```

    Cùng một module mang phần còn lại của bộ công cụ: `app.ws(...)` cho
    WebSocket, `app.rpc(...)` cho RPC, `app.static(...)` cho tài nguyên
    tĩnh, `build_cluster` cho worker thread-per-core, `init_https_ephemeral`
    cho HTTPS không cần tệp chứng chỉ, cùng `listen_udp` và `init_http3` cho
    HTTP/3.
