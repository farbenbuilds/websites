### Trước khi bắt đầu [#before-you-start]

Hoàn thành [Cài đặt](/docs/getting-started/installation) và
[Quickstart](/docs/getting-started/quickstart) trước. Ví dụ giả định:

- Zig 0.16.0 đã cài từ [ziglang.org/download](https://ziglang.org/download/).
- Dự án đã có dependency `uWebZockets` phiên bản 2.1.6.
- `src/main.zig` chứa chương trình bạn muốn chạy.
- `zig build run` khởi động dự án.

## Canonical programs [#canonical-programs]

Mỗi trang document một chương trình trong thư mục `examples/` của framework.
Trang cung cấp complete source, consumer `build.zig` wiring, run command,
expected output, capacity mà example chọn và một variation. Bắt đầu với
[Hello world](/examples/hello-world), trang cũng chứa tutorial HTTP đầu tiên;
bảng bên dưới liệt kê các chương trình lớn hơn.

| Example                                                    | Shows                                          | Protocol                | Default port |
| ---------------------------------------------------------- | ---------------------------------------------- | ----------------------- | -----------: |
| [HTTPS server](/examples/https-server)                     | In-memory TLS certificate và ALPN              | HTTPS, HTTP/1.1, HTTP/2 |         3443 |
| [Shared-nothing cluster](/examples/shared-nothing-cluster) | Bốn worker, mỗi worker một slab và loop        | HTTP/1.1                |         3000 |
| [TLS cluster](/examples/tls-cluster)                       | Per-worker TLS context và runtime worker count | HTTPS, HTTP/1.1, HTTP/2 |         8443 |
| [Basic microservice](/examples/basic-microservice)         | `Presets.microservice`, JSON, query parsing    | HTTP/1.1                |         3000 |
| [Custom builder](/examples/custom-builder)                 | Fluent capacity và `slab_bytes()`              | HTTP/1.1                |         3001 |
| [Chat server](/examples/chat-server)                       | WebSocket open, message, close và pub/sub      | WebSocket               |         3000 |
| [RPC server](/examples/rpc-server)                         | Typed JSON-RPC procedure                       | JSON-RPC                |         3000 |
| [HTTP/3 server](/examples/http3-server)                    | QUIC listener và in-memory TLS                 | HTTP/3                  |     8443 UDP |
| [Delayed response](/examples/delay-server)                 | Async token và timing wheel                    | HTTP/1.1                |         3000 |

## Chạy example trong project của bạn [#run-an-example-in-your-project]

<Steps>
  <Step title="Thêm dependency">
    ```sh
    zig fetch --save 'https://github.com/farbenbuilds/uWebZockets/archive/refs/tags/v2.1.6.tar.gz'
    ```
  </Step>
  <Step title="Wire module">
    ```zig build.zig
    const std = @import("std");

    pub fn build(b: *std.Build) void {
        const target = b.standardTargetOptions(.{});
        const optimize = b.standardOptimizeOption(.{});
        const uz = b.dependency("uWebZockets", .{
            .target = target,
            .optimize = optimize,
        });

        const exe = b.addExecutable(.{
            .name = "example",
            .root_module = b.createModule(.{
                .root_source_file = b.path("src/main.zig"),
                .target = target,
                .optimize = optimize,
            }),
        });
        exe.root_module.addImport("uWebZockets", uz.module("uWebZockets"));
        b.installArtifact(exe);

        const run = b.addRunArtifact(exe);
        b.step("run", "Run the example").dependOn(&run.step);
    }
    ```

  </Step>
  <Step title="Copy chương trình">
    Copy source trên trang vào `src/main.zig`. Full source link trên mỗi
    canonical page trỏ tới file framework mà trang mirror.
  </Step>
  <Step title="Build và chạy">
    ```sh
    zig build run
    ```
  </Step>
  <Step title="Verify">
    Dùng lệnh `curl` hoặc `wscat` trên example page. TLS cluster và HTTP/3
    example cài signal watcher và drain khi Ctrl+C; các example còn lại dừng
    ngay.
  </Step>
</Steps>

## Upstream build steps [#upstream-build-steps]

Framework repository cũng expose mỗi canonical program thành một named build
step, ví dụ `zig build hello_world` hoặc `zig build tls_cluster`. Các lệnh đó
chạy trong framework checkout và là contributor shortcut; chúng không phải
consumer path. Trong project của bạn, dùng `zig build run` sau khi copy source.
