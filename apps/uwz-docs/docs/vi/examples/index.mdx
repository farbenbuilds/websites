## Run an example in your project [#run-an-example-in-your-project]

<Steps>
  <Step title="Add the dependency">
    ```sh
    zig fetch --save 'https://github.com/farbenbuilds/uWebZockets/archive/refs/tags/v2.1.6.tar.gz'
    ```
  </Step>
  <Step title="Wire the module">
    ```zig build.zig
    const std = @import("std");

    pub fn build(b: *std.Build) void {
        const target = b.standardTargetOptions(.{});
        const optimize = b.standardOptimizeOption(.{});
        const uz = b.dependency("uWebZockets", .{
            .target = target,
            .optimize = optimize,
        });

        const exe = b.addExecutable(.{
            .name = "example",
            .root_module = b.createModule(.{
                .root_source_file = b.path("src/main.zig"),
                .target = target,
                .optimize = optimize,
            }),
        });
        exe.root_module.addImport("uWebZockets", uz.module("uWebZockets"));
        b.installArtifact(exe);

        const run = b.addRunArtifact(exe);
        b.step("run", "Run the example").dependOn(&run.step);
    }
    ```

  </Step>
  <Step title="Copy the program">
    Copy source trên trang vào `src/main.zig`. Full source link trên mỗi trang
    trỏ tới file framework mà trang mirror.
  </Step>
  <Step title="Build and run">
    ```sh
    zig build run
    ```
  </Step>
  <Step title="Verify">
    Dùng lệnh `curl` hoặc `wscat` trên example page. TLS cluster và HTTP/3
    example cài signal watcher và drain khi Ctrl+C; các example còn lại dừng
    ngay.
  </Step>
</Steps>

## Upstream build steps [#upstream-build-steps]

Framework repository cũng expose mỗi chương trình thành một named build step, ví
dụ `zig build hello_world` hoặc `zig build tls_cluster`. Các lệnh đó chạy trong
framework checkout và là contributor shortcut; chúng không phải consumer path.
Trong project của bạn, dùng `zig build run` sau khi copy source.

## Capacities chosen by the examples [#capacities-chosen-by-the-examples]

| Example                |    Connections | Write queue |   Body | Message | Why                             |
| ---------------------- | -------------: | ----------: | -----: | ------: | ------------------------------- |
| Hello world            |            128 |      64 KiB | 16 KiB |  16 KiB | Small default footprint         |
| HTTPS server           |            128 |      64 KiB | 16 KiB |  16 KiB | Same shape, TLS only            |
| Shared-nothing cluster | 128 per worker |      32 KiB | 16 KiB |  16 KiB | Four small workers              |
| TLS cluster            |   128 to 2,048 |      64 KiB | 16 KiB |  16 KiB | Benchmark controls              |
| Basic microservice     |            256 |      16 KiB | 64 KiB |   8 KiB | JSON request/response           |
| Custom builder         |              4 |     256 KiB | 50 MiB |  16 KiB | Large uploads, few peers        |
| Chat server            |            128 |      64 KiB | 16 KiB |  16 KiB | Default WebSocket path          |
| RPC server             |            128 |      64 KiB | 16 KiB |  16 KiB | Small typed payloads            |
| HTTP/3 server          |            128 |      64 KiB | 16 KiB |  16 KiB | QUIC request/response           |
| Delayed response       |            128 |      64 KiB | 16 KiB |  16 KiB | Parked response dùng timer slot |
