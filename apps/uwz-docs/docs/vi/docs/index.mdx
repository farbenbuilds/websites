µWebZockets 2.1.6 là framework server zero-allocation, shared-nothing cho Zig
0.16.0. Một API `Request` và `Response` phục vụ HTTP/1.1, HTTP/2, HTTP/3,
WebSocket và JSON-RPC từ các slab có giới hạn được cấp phát một lần lúc khởi
động.

Trang này dẫn bạn đến tài liệu theo từng tác vụ. Mỗi trang nêu rõ hành vi,
giới hạn và tính năng chưa được hỗ trợ. Nội dung giới thiệu dự án nằm ở
[trang chủ](/vi).

## Phạm vi tính năng [#feature-coverage]

Bảng này là ma trận tính năng ra mắt của site. Danh sách ranh giới đầy đủ, gồm
các module helper-only và experimental, nằm trong roadmap của repository.

| Surface                 | Trạng thái               | Bắt đầu tại                                                        |
| ----------------------- | ------------------------ | ------------------------------------------------------------------ |
| Định tuyến HTTP/1.1     | Được hỗ trợ              | [HTTP server đầu tiên](/docs/examples/first-http-server)           |
| Định tuyến HTTP/2       | Được hỗ trợ, có giới hạn | [µWebZockets là gì](/docs/what-is-uwebsockets)                     |
| WebSocket server        | Được hỗ trợ              | [WebSocket đầu tiên](/docs/examples/first-websocket)               |
| JSON-RPC 2.0            | Được hỗ trợ              | [JSON-RPC service đầu tiên](/docs/examples/first-json-rpc-service) |
| Kết thúc TLS 1.3        | Được hỗ trợ              | [TLS server đầu tiên](/docs/examples/first-tls-server)             |
| Cluster thread-per-core | Được hỗ trợ trên TCP     | [Cluster đầu tiên](/docs/examples/first-cluster)                   |
| Định tuyến HTTP/3       | Được hỗ trợ              | [HTTP/3 server đầu tiên](/docs/examples/first-http3-server)        |
| Cluster HTTP/3          | Chưa được hỗ trợ         | [Ranh giới HTTP/3](/docs/examples/first-http3-server#boundaries)   |
| WebTransport live       | Chưa được hỗ trợ         | [Ranh giới HTTP/3](/docs/examples/first-http3-server#boundaries)   |
| WebSocket client        | Chưa được hỗ trợ         | [FAQ](/docs/getting-started/faq#client-scope)                      |

[Đọc roadmap và ranh giới đầy đủ](https://github.com/farbenbuilds/uWebZockets/blob/main/docs/roadmap.md)
