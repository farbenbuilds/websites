µWebZockets 2.1.6 là framework server zero-allocation, shared-nothing cho Zig
0.16.0. Một API `Request` và `Response` phục vụ HTTP/1.1, HTTP/2, HTTP/3,
WebSocket và JSON-RPC từ các slab có giới hạn được cấp phát một lần lúc khởi
động.

Trang này là điểm vào theo tác vụ. Repository vẫn là nguồn chuẩn cho hành vi
wire, giới hạn và bằng chứng phát hành.

## Helpers

Các tiện ích nhỏ, có thể kết hợp nằm trong lớp HTTP helper. Phân tích query và
form, multipart, cookie, nén, ETag và conditional GET, thương lượng `Accept`,
primitive fetch và stream, cùng adapter WebSocket stream được ghi trong
repository cho đến khi Helpers hub có trên site này.

[Đọc request và response helpers](https://github.com/farbenbuilds/uWebZockets/blob/main/docs/http.md#request-and-response-helpers)

## Phạm vi tính năng [#feature-coverage]

Bảng này tóm tắt bề mặt ra mắt. Ma trận đầy đủ, gồm các module helper-only và
experimental, nằm trong roadmap của repository.

| Bề mặt                  | Trạng thái         | Bắt đầu tại                                                               |
| ----------------------- | ------------------ | ------------------------------------------------------------------------- |
| Định tuyến HTTP/1.1     | Supported          | [HTTP server đầu tiên](/docs/getting-started/first-http-server)           |
| WebSocket server        | Supported          | [WebSocket đầu tiên](/docs/getting-started/first-websocket)               |
| JSON-RPC 2.0            | Supported          | [JSON-RPC service đầu tiên](/docs/getting-started/first-json-rpc-service) |
| Kết thúc TLS 1.3        | Supported          | [TLS server đầu tiên](/docs/getting-started/first-tls-server)             |
| Cluster thread-per-core | Supported trên TCP | [Cluster đầu tiên](/docs/getting-started/first-cluster)                   |
| Định tuyến HTTP/3       | Supported          | [HTTP/3 server đầu tiên](/docs/getting-started/first-http3-server)        |
| Cluster HTTP/3          | Not supported      | [Ranh giới HTTP/3](/docs/getting-started/first-http3-server#boundaries)   |
| WebTransport live       | Not supported      | [Ranh giới HTTP/3](/docs/getting-started/first-http3-server#boundaries)   |
| WebSocket client        | Not supported      | [FAQ](/docs/getting-started/faq#client-scope)                             |

[Đọc ma trận tính năng và roadmap đầy đủ](https://github.com/farbenbuilds/uWebZockets/blob/main/docs/roadmap.md)
