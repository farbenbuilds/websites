TLS termination là một lựa chọn initializer. Listener, router và handler giữ
nguyên; chỉ nguồn credential và client policy thay đổi.

## Vấn đề

Bạn cần HTTPS khi phát triển mà không có file certificate, rồi cùng server đó ở
production với PEM thật, và tuỳ chọn kiểm tra client certificate.

## Giả định

- Có Zig 0.16.0 và `curl`.
- Production dùng certificate chain và private key trên đĩa.
- TLS chỉ 1.3. HTTP/1.1 và HTTP/2 dùng chung một context; HTTP/3 dùng context
  khác.
- Process đọc credential một lần. Rotate là rolling restart.

## Viết chương trình

```zig src/main.zig
const std = @import("std");
const uz = @import("uWebZockets");

fn index(_: *uz.Request, res: *uz.Response) void {
    res.text("hello over TLS") catch |err| std.log.err("response failed: {}", .{err});
}

pub fn main(init: std.process.Init) !void {
    var app = try uz.App(128).init_https_ephemeral(init.io);
    defer app.deinit();

    _ = try app.get("/", index);
    try app.catch_shutdown_signals();
    try app.listen("0.0.0.0", 3443);
    try app.run();
}
```

`init_https_ephemeral` tạo ECDSA P-256 key và certificate self-signed trong
memory trước khi loop chạy. Certificate phủ `localhost`, `127.0.0.1` và `::1`,
mang `serverAuth`, hiệu lực 90 ngày. Nó không export được và được tạo lại mỗi
lần start.

## Kiểm tra

```sh
zig build run
```

```sh
curl -k -v https://127.0.0.1:3443/
```

```console
hello over TLS
* ALPN: server accepted h2
```

`-k` tắt verification. Chỉ dùng cho certificate sinh tự động. Dòng verbose cho
thấy ALPN đàm phán: `curl` có HTTP/2 nhận `h2`, nếu không là `http/1.1`. HTTP/3
không được chào trên TCP listener này.

## ALPN và early data

| Policy                 | Giá trị                           |
| ---------------------- | --------------------------------- |
| TLS version            | Chỉ 1.3                           |
| TCP ALPN               | `h2`, rồi `http/1.1`              |
| QUIC ALPN              | Chỉ `h3`                          |
| 0-RTT trên TCP         | Bật trừ khi cấu hình mTLS         |
| Method trước handshake | `GET`, `HEAD`, `OPTIONS`, `TRACE` |
| Method khác ở 0-RTT    | `425 Too Early`                   |

Early data có thể bị replay, nên chỉ safe method chạy trước khi handshake xác
nhận. Handler `GET` có mutate state vẫn phá giả định đó; giữ mutation sau `POST`
hoặc method không an toàn.

## Giả định capacity

| Tài nguyên    | Giới hạn                            | Hệ quả                               |
| ------------- | ----------------------------------- | ------------------------------------ |
| Connection    | `max_clients`                       | Handshake state là per connection    |
| TLS context   | Một mỗi application, một mỗi worker | Không chia session cache giữa worker |
| Credential    | Đọc một lần lúc startup             | Rotate phải restart process          |
| Handshake CPU | Một core mỗi worker loop            | Handshake tranh CPU với request      |

Ticket key per worker nghĩa là session resume trên worker khác phải handshake
đầy đủ. Load balancer không session affinity sẽ thấy tỉ lệ resumption thấp hơn
một process.

## Hành vi khi lỗi

| Điều kiện                  | Kết quả                       |
| -------------------------- | ----------------------------- |
| Không đọc được certificate | `error.CertificateLoadFailed` |
| Key không khớp certificate | `error.PrivateKeyLoadFailed`  |
| Client từ chối chain       | Handshake fail trước request  |
| Unsafe method ở 0-RTT      | `425 Too Early`               |
| Không có cipher chung      | Handshake fail                |
| Certificate hết hạn        | Client fail handshake         |

## Biến thể

### PEM cho production

```zig
var app = try uz.App(128).init_https(
    init.io,
    "certs/fullchain.pem",
    "certs/privkey.pem",
);
defer app.deinit();
```

Certificate là PEM chain với leaf đầu tiên; key là PEM private key. BoringSSL
kiểm tra cặp lúc load, nên mismatch fail lúc startup thay vì handshake đầu.
Đường dẫn là Zig slice kết thúc NUL; string literal đã có kiểu đó.

Worker group dùng cùng file qua `group.enable_https(cert, key)` sau `configure`
và trước `listen`.

### Mutual TLS

```zig
var app = try uz.App(128).init_https_mtls(
    init.io,
    "certs/fullchain.pem",
    "certs/privkey.pem",
    .{ .mode = .required, .ca_path = "certs/client-ca.pem" },
);
defer app.deinit();
```

`.required` từ chối client không có chain hợp lệ trước khi HTTP parser chạy.
`.optional` xác minh khi client gửi certificate và vẫn nhận anonymous client.
mTLS tắt TCP early data vì client certificate đến sau flight đầu. Client auth
chỉ trên TCP; HTTP/3 context không yêu cầu certificate.

CRL trong bundle được load nhưng revocation không được enforce, nên certificate
đã thu hồi vẫn hợp lệ đến khi hết hạn.
