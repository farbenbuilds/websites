Mỗi guide là một recipe hoàn chỉnh cho một application shape. Guide đưa ra một
chương trình nhỏ nhưng trọn vẹn, nêu capacity mà nó giả định, cho thấy request bị
từ chối trông thế nào, và kết thúc bằng hai variation để bạn tuỳ biến. Guide không
dạy lại framework: khi cần contract đầy đủ của một helper, guide link tới trang
reference sở hữu helper đó.

## Đọc một guide

| Phần                 | Trả lời câu hỏi gì                                 |
| -------------------- | -------------------------------------------------- |
| Bài toán             | Behavior bạn đang muốn ship                        |
| Giả định             | Toolchain, transport, số worker và trust boundary  |
| Chương trình         | Chương trình hoàn chỉnh để copy vào `src/main.zig` |
| Verification         | Command chứng minh cả success path và failure path |
| Capacity assumptions | Các bound chương trình dựa vào và nguồn của chúng  |
| Failure behavior     | Status code và error cho từng input bị từ chối     |
| Variations           | Hai thay đổi giữ nguyên invariant                  |

Mọi chương trình là application code bình thường. Không guide nào yêu cầu clone,
build hay test framework repository, và không guide nào allocation không bound
trên request path.

## Guide không phải là gì

Guide không phải reference cho một helper, bảng status code hay danh sách capacity.
Những thứ đó nằm ở trang sở hữu symbol. Khi guide và reference page mâu thuẫn,
reference page đúng và guide là defect.
