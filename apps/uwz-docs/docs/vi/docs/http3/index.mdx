`init_http3` tạo hai TLS context: TCP quảng bá `h2` và `http/1.1`, còn QUIC quảng
bá `h3`. Cùng các route phục vụ cả ba. Phần này mô tả HTTP/3 request path live,
QUIC policy và ranh giới giữ WebTransport ngoài supported surface.

Live path là request/response server có giới hạn. Nó không phải QUIC platform đa
dụng và không chia sẻ mọi tính năng vận hành của HTTP/1.1. Chương trình canonical
là [HTTP/3 server example](/examples/http3-server).

## Khởi động

```zig
var server = try uz.App(128).init_http3_ephemeral(init.io);
defer server.deinit();

_ = try server.get("/", index);
try server.listen_udp("0.0.0.0", 8443);
try server.catch_shutdown_signals();
try server.run();
```

`App` phải giữ địa chỉ ổn định sau `listen_udp`; QUIC engine giữ con trỏ tới nó.
Không move nó vào container có thể reallocate.

| Listener     | Protocol                              |
| ------------ | ------------------------------------- |
| `listen`     | TCP với TLS, ALPN `h2` rồi `http/1.1` |
| `listen_udp` | QUIC, chỉ ALPN `h3`                   |

## Ranh giới

| Tính năng                 | Trạng thái                                  |
| ------------------------- | ------------------------------------------- |
| HTTP/3 request routing    | Supported                                   |
| 0-RTT                     | Không hỗ trợ; bị từ chối trên live listener |
| HTTP/3 clustering         | Không hỗ trợ                                |
| Metrics registry          | Không cập nhật; chỉ development log         |
| WebTransport live path    | Không hỗ trợ; CONNECT nhận `501`            |
| WebTransport helper model | Helper-only, draft-16                       |
| QUIC client               | Không ship                                  |

:::warning[WebTransport chưa live]
`uz.webtransport` và `uz.http3_extensions` tồn tại, nhưng live lsquic listener
không kết nối tới chúng. CONNECT request nhận `501 Not Implemented`. Không mô tả
WebTransport là transport được hỗ trợ trên version này.
:::
