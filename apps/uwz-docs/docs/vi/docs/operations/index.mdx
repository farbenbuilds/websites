Phần này dành cho maintainer và contributor build và kiểm tra chính µWebZockets:
framework repository, dependency đã pin, các test gate và công việc release,
runtime. Nếu bạn đang thêm µWebZockets vào application, hãy bắt đầu với
[Installation](/docs/getting-started/installation). Trang đó dùng
`zig fetch --save`; phần này bắt đầu từ một clone của framework.

Các trang ở đây mô tả command chạy trên checkout của framework. Chúng không phải
application build step và không bắt buộc để dùng package.

## Phần này được tổ chức thế nào

| Nhóm     | Câu hỏi mà nhóm trả lời                                               |
| -------- | --------------------------------------------------------------------- |
| Build    | Cần toolchain, build graph và target nào?                             |
| Verify   | Gate nào chứng minh thay đổi tôi vừa làm?                             |
| Release  | Thứ gì được ship, version hóa ra sao và pin những gì?                 |
| Operate  | Đọc log, metrics và dừng process mà không mất việc đang chạy thế nào? |
| Advanced | Dùng C ABI, edge, kernel-bypass và kTLS surface thế nào?              |

## Phần này giả định gì

| Giả định                   | Chi tiết                                                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Compiler                   | Zig 0.16.0. Nix shell cung cấp compiler; bản cài thuần phải khớp minor version.                                        |
| Host platform              | Linux chạy hosted matrix trên `x86_64` và `aarch64`. macOS được hỗ trợ và cross-compile; Windows có runtime job riêng. |
| Quyền truy cập repository  | Một clone của `farbenbuilds/uWebZockets`, kèm submodule `vendor/h1spec` cho gate h1spec.                               |
| Network ở lần chạy đầu     | Zig fetch các package dependency đã pin vào global cache và local cache.                                               |
| Không cần system toolchain | BoringSSL, lsquic, ls-qpack, ls-hpack, libdeflate và zlib được build từ source đã pin.                                 |
