Operations gồm hai công việc khác nhau. Một số trang giải thích cách thay đổi,
kiểm tra và phát hành chính repository µWebZockets; đó là hướng dẫn đóng góp cho
[farbenbuilds/uWebZockets](https://github.com/farbenbuilds/uWebZockets). Các
trang còn lại giải thích cách vận hành application đã cài package bằng
`zig fetch --save`.

Không chạy command dành cho framework contributor trên application project. Hai
build graph khác nhau: framework checkout sở hữu `builds/`, các test step và
script release; application project sở hữu `build.zig`, pin package trong
`build.zig.zon` và import public module `uWebZockets`.

## Advanced surfaces for applications

Đây là application feature, không phải framework build step. Các trang giả định
package đã được thêm bằng `zig fetch --save`; mỗi trang chỉ ra consumer
`build.zig` wiring hoặc public module import cần thiết.

<CardGroup cols={2}>
  <Card title="WASM edge targets" href="/docs/operations/wasm" icon="cpu">
    Build edge module freestanding hoặc WASI từ dependency và gọi các export có bound.
  </Card>
  <Card title="eBPF latency histogram" href="/docs/operations/ebpf" icon="activity">
    Compile XDP object trong application, pin latency map và đọc packet bucket.
  </Card>
  <Card title="kTLS" href="/docs/operations/ktls" icon="key-round">
    Import `uz.ktls` và program kernel TLS record state trên socket application đã sở hữu.
  </Card>
  <Card title="AF_XDP" href="/docs/operations/af-xdp" icon="network">
    Import `uz.xdp_transport` và `uz.xdp`, compile redirect và drive ring từ process của bạn.
  </Card>
</CardGroup>

| Surface | Sau `zig fetch --save`                                    | Public entry point           |
| ------- | --------------------------------------------------------- | ---------------------------- |
| WASM    | Resolve target `wasm32` trong `build.zig` và cài artifact | Artifact của dependency      |
| eBPF    | Compile C source của package bằng step trong `build.zig`  | `uz.ebpf`                    |
| kTLS    | Import module; không cần build step                       | `uz.ktls`                    |
| AF_XDP  | Compile redirect và import transport                      | `uz.xdp`, `uz.xdp_transport` |

## Section này giả định gì

| Giả định                   | Chi tiết                                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Compiler                   | Zig 0.16.0. Nix shell cung cấp compiler; bản cài thường phải khớp minor version.                                          |
| Host platform              | Linux chạy hosted matrix trên `x86_64` và `aarch64`. macOS được hỗ trợ và cross-compile; Windows bị gate bởi runtime job. |
| Repository access          | Trang contributor dùng clone của `farbenbuilds/uWebZockets`; trang application dùng `zig fetch --save`.                   |
| Network ở lần build đầu    | Zig fetch các dependency package đã pin vào global cache và local cache.                                                  |
| Không cần system toolchain | BoringSSL, lsquic, ls-qpack, ls-hpack, libdeflate và zlib được compile từ source đã pin.                                  |
