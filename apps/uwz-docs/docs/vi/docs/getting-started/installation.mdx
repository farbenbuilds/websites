Trang này cài Zig và thêm µWebZockets vào project của bạn.

## Điều kiện trước

| Yêu cầu         | Chi tiết                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------- |
| Zig             | Đúng 0.16.0. Kiểm tra bằng `zig version`.                                                |
| Host            | Linux hoặc macOS trên `x86_64` hoặc `aarch64`. Windows có job compile và runtime native. |
| Mạng            | Zig tải source dependency được pin trong lần build đầu.                                  |
| Toolchain C/C++ | Không cần riêng. Zig biên dịch source dependency được pin.                               |

## Tải Zig

Tải Zig 0.16.0 từ [ziglang.org/download](https://ziglang.org/download/) và thêm
`zig` vào `PATH`. Kiểm tra phiên bản:

```sh
zig version
```

```text
0.16.0
```

## Thêm package

Từ thư mục gốc project của bạn, fetch bản phát hành được pin:

```sh
zig fetch --save 'https://github.com/farbenbuilds/uWebZockets/archive/refs/tags/v2.1.6.tar.gz'
```

Lệnh thêm package vào `build.zig.zon` dưới tên `uWebZockets`. Dùng cùng URL khi
nâng cấp để dependency luôn tái lập được.

## Nối module

Thêm module vào executable trong `build.zig`:

```zig
const uz = b.dependency("uWebZockets", .{
    .target = target,
    .optimize = optimize,
});
exe.root_module.addImport("uWebZockets", uz.module("uWebZockets"));
```

Chương trình consumer hoàn chỉnh nằm trong [quickstart](/docs/getting-started/quickstart).

## Kỳ vọng với package

- Package export một module tên `uWebZockets`.
- Module mang metadata link native và thứ tự dependency, nên bạn không phải
  link BoringSSL, lsquic, zlib hay libdeflate bằng tay.
- Bản phát hành là source archive. Không có archive binary theo nền tảng, nên
  Zig biên dịch dependency được pin trong lần dùng đầu.

## Build đầu và dùng offline

Build đầu chậm hơn vì Zig biên dịch BoringSSL, lsquic, libdeflate và zlib từ
source. Build sau dùng lại `~/.cache/zig` và cache trong project.

Để build không cần mạng, nạp cả hai cache trên máy có mạng trước, rồi dùng
lại. URL và hash dependency được pin trong `build.zig.zon`; Zig xác minh hash
khi giải nén package.

## Kiểm tra cài đặt

Thêm server từ [Quickstart](/docs/getting-started/quickstart), rồi chạy:

```sh
zig build run
```

Development log in ra phiên bản, thời gian khởi động và địa chỉ local. Dừng
server bằng Ctrl+C.

## Lỗi thường gặp lần đầu

| Triệu chứng                  | Nguyên nhân và cách sửa                                                                      |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| `error: invalid Zig version` | Compiler đang dùng không phải 0.16.0. Tải Zig 0.16.0 và chọn nó.                             |
| Hash dependency không khớp   | Cache package hỏng hoặc URL đổi. Xóa package đã cache và fetch lại. Không sửa hash được pin. |
| Build đầu có vẻ treo         | Đang biên dịch source C và C++ đi kèm. Kiểm tra CPU và đĩa trước khi ngắt.                   |
| Tải dependency thất bại      | Kiểm tra kết nối mạng tới GitHub, rồi chạy lại lệnh `zig fetch`.                             |
