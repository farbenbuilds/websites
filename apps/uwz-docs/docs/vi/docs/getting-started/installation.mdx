Trang này hướng dẫn bạn cài Zig và thêm µWebZockets vào dự án.

## Điều kiện trước

| Yêu cầu         | Chi tiết                                                                              |
| --------------- | ------------------------------------------------------------------------------------- |
| Zig             | Đúng 0.16.0. Kiểm tra bằng `zig version`.                                             |
| Máy             | Linux hoặc macOS trên `x86_64` hoặc `aarch64`. Windows có job compile và job runtime. |
| Mạng            | Zig tải source của các dependency đã pin trong lần build đầu.                         |
| C/C++ toolchain | Không cần cài riêng. Zig biên dịch source của các dependency đã pin.                  |

## Tải Zig

Tải Zig 0.16.0 từ [ziglang.org/download](https://ziglang.org/download/) và thêm
`zig` vào `PATH`. Kiểm tra phiên bản:

```sh
zig version
```

```text
0.16.0
```

## Thêm package vào dự án

Từ thư mục gốc của dự án, fetch bản phát hành đã pin:

```sh
zig fetch --save 'https://github.com/farbenbuilds/uWebZockets/archive/refs/tags/v2.1.6.tar.gz'
```

Lệnh này thêm package vào `build.zig.zon` dưới tên `uWebZockets`. Khi nâng cấp,
hãy pin URL của bản phát hành mới để dependency luôn tái lập được.

## Nối module

Thêm module vào executable trong `build.zig`:

```zig
const uz = b.dependency("uWebZockets", .{
    .target = target,
    .optimize = optimize,
});
exe.root_module.addImport("uWebZockets", uz.module("uWebZockets"));
```

Chương trình hoàn chỉnh sử dụng package nằm trong [quickstart](/docs/getting-started/quickstart).

## Kỳ vọng với package

- Package export module `uWebZockets`.
- Module mang metadata link native và thứ tự dependency, nên bạn không phải
  tự link BoringSSL, lsquic, zlib hay libdeflate.
- Bản phát hành là source archive. Không có binary archive cho từng nền tảng,
  nên Zig biên dịch dependency đã pin trong lần dùng đầu.

## Build đầu và dùng offline

Build đầu tiên chậm hơn vì Zig biên dịch BoringSSL, lsquic, libdeflate và zlib
từ source. Các build sau dùng lại `~/.cache/zig` và cache trong dự án.

Để build không cần mạng, nạp cả hai cache trên máy có mạng trước, rồi dùng
lại. URL và hash dependency được pin trong `build.zig.zon`; Zig xác minh hash
khi giải nén package.

## Kiểm tra cài đặt

Thêm server từ [Quickstart](/docs/getting-started/quickstart), rồi chạy:

```sh
zig build run
```

Development log hiển thị phiên bản, thời gian khởi động và địa chỉ cục bộ. Dừng
server bằng Ctrl+C.

## Lỗi thường gặp khi bắt đầu

| Triệu chứng                  | Nguyên nhân và cách sửa                                                                      |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| `error: invalid Zig version` | Compiler đang dùng không phải 0.16.0. Tải Zig 0.16.0 và chọn nó.                             |
| Hash dependency không khớp   | Package cache hỏng hoặc URL đổi. Xóa package đã cache và fetch lại. Không sửa hash được pin. |
| Build đầu có vẻ treo         | Zig đang biên dịch source C và C++ đi kèm. Kiểm tra CPU và đĩa trước khi ngắt.               |
| Tải dependency thất bại      | Kiểm tra kết nối mạng tới GitHub, rồi chạy lại lệnh `zig fetch`.                             |
