Quickstart này tạo project Zig mới, thêm µWebZockets làm dependency và đạt
phản hồi `200 OK` đã kiểm tra. Nó dùng một chương trình hoàn chỉnh và một lệnh
build.

## Điều kiện trước

- Zig 0.16.0 trên host được hỗ trợ.
- Terminal trong thư mục bạn giữ project.
- `curl`.

## Tạo project

<Steps>
  <Step title="Khởi tạo project Zig">
    ```sh
    mkdir hello-uwz
    cd hello-uwz
    zig init
    ```

    `zig init` tạo `build.zig`, `build.zig.zon` và cây source khởi đầu. Bạn
    thay executable được tạo bằng server bên dưới.

  </Step>
  <Step title="Thêm dependency">
    ```sh
    zig fetch --save 'git+https://github.com/farbenbuilds/uWebZockets#VERSION_OR_COMMIT'
    ```

    Thay `VERSION_OR_COMMIT` bằng tag phát hành như `v2.1.6` hoặc hash commit
    đầy đủ.

  </Step>
  <Step title="Nối module">
    Thay `build.zig` bằng file này:

    ```zig
    const std = @import("std");

    pub fn build(b: *std.Build) void {
        const target = b.standardTargetOptions(.{});
        const optimize = b.standardOptimizeOption(.{});

        const uz = b.dependency("uWebZockets", .{
            .target = target,
            .optimize = optimize,
        });

        const exe = b.addExecutable(.{
            .name = "hello-uwz",
            .root_module = b.createModule(.{
                .root_source_file = b.path("src/main.zig"),
                .target = target,
                .optimize = optimize,
            }),
        });
        exe.root_module.addImport("uWebZockets", uz.module("uWebZockets"));
        b.installArtifact(exe);

        const run = b.addRunArtifact(exe);
        const runStep = b.step("run", "Run the hello server");
        runStep.dependOn(&run.step);
    }
    ```

  </Step>
  <Step title="Viết server">
    Thay `src/main.zig` bằng:

    ```zig
    const std = @import("std");
    const uz = @import("uWebZockets");

    fn hello(_: *uz.Request, res: *uz.Response) void {
        res.text("hello from a dependency") catch |err| {
            std.log.err("response failed: {}", .{err});
        };
    }

    pub fn main(init: std.process.Init) !void {
        var app = try uz.App(128).init(init.io);
        defer app.deinit();

        _ = try app.get("/", hello);
        try app.catch_shutdown_signals();
        try app.listen("0.0.0.0", 3000);
        try app.run();
    }
    ```

  </Step>
  <Step title="Chạy">
    ```sh
    zig build run
    ```

    Giữ server chạy và mở terminal thứ hai.

  </Step>
  <Step title="Kiểm tra phản hồi">
    ```sh
    curl -i http://127.0.0.1:3000/
    ```

    Phản hồi bắt đầu bằng `HTTP/1.1 200 OK` và kết thúc bằng:

    ```text
    hello from a dependency
    ```

  </Step>
</Steps>

## Chuyện gì vừa xảy ra

| Lệnh gọi                       | Tác dụng                                            |
| ------------------------------ | --------------------------------------------------- |
| `uz.App(128).init(init.io)`    | Cấp một slab cho 128 kết nối đồng thời và tạo loop. |
| `app.get("/", hello)`          | Đăng ký route `GET /` đồng bộ trước khi listen.     |
| `app.catch_shutdown_signals()` | Cài watcher SIGINT và SIGTERM để drain server.      |
| `app.listen("0.0.0.0", 3000)`  | Bind listener TCP và khóa đăng ký route.            |
| `app.run()`                    | Chạy event loop đến khi shutdown hoàn tất.          |
| `app.deinit()`                 | Giải phóng slab sau khi loop đã drain.              |

Chữ ký handler là `fn (*uz.Request, *uz.Response) void`. Slice request được
mượn trong callback, và `res.text` copy body vào write queue có giới hạn trước
khi trả về.

## Đổi port

Truyền port khác cho `listen`:

```zig
try app.listen("127.0.0.1", 8080);
```

Bind `127.0.0.1` giữ server trên interface loopback. Bind `0.0.0.0` nhận kết
nối trên mọi interface local.

## Dừng server

Nhấn Ctrl+C trong terminal server. Signal watcher yêu cầu đường drain bình
thường, nên kết nối đang mở hoàn tất và `deinit` giải phóng slab. Kill cưỡng
bức bỏ qua drain và không phải đường dừng bình thường.
