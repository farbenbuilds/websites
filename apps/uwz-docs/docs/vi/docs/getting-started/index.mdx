Phần này đưa bạn từ máy sạch đến server đang chạy. Nó bao gồm cài đặt, dự án
đầu tiên, mô hình ứng dụng và các câu trả lời cần biết trước khi thêm route
giao thức.

## Trước khi bắt đầu

Bạn cần:

- Zig 0.16.0 từ [ziglang.org/download](https://ziglang.org/download/). Kiểm tra
  bằng `zig version`.
- Máy Linux hoặc macOS trên `x86_64` hoặc `aarch64`. Windows có job compile và
  job runtime, nhưng chỉ được hỗ trợ chính thức sau khi job runtime của bản phát
  hành pass.
- `curl` cho các ví dụ HTTP.

## Quy ước trong hướng dẫn

Mọi ví dụ Zig khai báo `main` hoàn chỉnh và import `uWebZockets`. Ví dụ dùng
`std.process.Init` và `init.io` vì Zig 0.16 truyền I/O implementation vào
`main`.

Xử lý lỗi là tường minh. Handler không thể phục hồi sẽ ghi log lỗi hoặc trả status;
hướng dẫn không giấu lỗi bằng `catch {}` trừ khi chữ ký callback không thể trả
lỗi và trang giải thích lý do.

Lệnh dùng code fence `sh`; output dự kiến dùng `text` hoặc `console`. Lệnh giả
định thư mục gốc của dự án trừ khi bước khác nói rõ.
