Phần này đưa bạn từ máy sạch đến server đang chạy, rồi đến các biến thể
WebSocket, JSON-RPC, TLS, cluster và HTTP/3. Mỗi hướng dẫn là một chương trình
hoàn chỉnh có thể build và kiểm tra bằng `curl` hoặc WebSocket client.

## Trước khi bắt đầu

Bạn cần:

- Zig 0.16.0. Kiểm tra bằng `zig version`.
- Host Linux hoặc macOS trên `x86_64` hoặc `aarch64`. Windows có job compile và
  runtime, nhưng hỗ trợ runtime chính thức chỉ sau khi job phát hành xanh.
- `curl` cho các ví dụ HTTP. Hướng dẫn HTTP/3 cần bản `curl` có hỗ trợ HTTP/3.
- Nix chỉ khi chọn đường Nix cho checkout repository.

## Quy ước trong hướng dẫn

Mọi ví dụ Zig khai báo `main` hoàn chỉnh và import `uWebZockets`. Ví dụ dùng
`std.process.Init` và `init.io` vì Zig 0.16 truyền implementation I/O qua
`main`.

Xử lý lỗi là tường minh. Handler không thể phục hồi sẽ log lỗi hoặc trả status;
hướng dẫn không giấu lỗi bằng `catch {}` trừ khi chữ ký callback không thể trả
lỗi và trang giải thích lý do.

Output terminal được hiển thị trong fence `console`. Lệnh giả định thư mục
gốc project trừ khi bước nói khác.
