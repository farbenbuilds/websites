Repository cung cấp ví dụ chạy được cho từng bề mặt được hỗ trợ. Mọi bước nhận
`-Doptimize=ReleaseSafe` cho bản build dạng production.

```sh
zig build -Doptimize=ReleaseSafe
```

Install mặc định ghi binary ví dụ vào `zig-out/bin`. Bảng ánh xạ mỗi bước với
hành vi, file source và trang site liên quan.

## HTTP và HTTPS

| Bước                           | Minh họa                                                   | Source                                                                                                            | Trang site                                                      |
| ------------------------------ | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `zig build hello_world`        | Route HTTP/1.1 tối thiểu trên `App(128)`, port 3000.       | [`hello_world.zig`](https://github.com/farbenbuilds/uWebZockets/blob/main/examples/hello_world.zig)               | [HTTP server đầu tiên](/docs/getting-started/first-http-server) |
| `zig build https_server`       | HTTPS trên port 3443 với chứng chỉ trong bộ nhớ.           | [`https_server.zig`](https://github.com/farbenbuilds/uWebZockets/blob/main/examples/https_server.zig)             | [TLS server đầu tiên](/docs/getting-started/first-tls-server)   |
| `zig build basic_microservice` | `Presets.microservice` với JSON helper và route `/health`. | [`basic_microservice.zig`](https://github.com/farbenbuilds/uWebZockets/blob/main/examples/basic_microservice.zig) | [Cài đặt](/docs/getting-started/installation)                   |
| `zig build custom_builder`     | Ghi đè fluent và đường request body 50 MiB trên port 3001. | [`custom_builder.zig`](https://github.com/farbenbuilds/uWebZockets/blob/main/examples/custom_builder.zig)         | [Cài đặt](/docs/getting-started/installation)                   |

## Target tuân thủ

Các target này dành cho xác minh repository, không phải onboarding ứng dụng:

| Bước                           | Mục đích                                 |
| ------------------------------ | ---------------------------------------- |
| `zig build h1spec`             | Bộ tuân thủ HTTP/1.1 trên port 8000.     |
| `zig build autobahn`           | Target tuân thủ RFC 6455 trên port 9001. |
| `zig build test --summary all` | Unit, C ABI và test giao thức.           |
| `zig build fuzz --fuzz=100K`   | Fuzz giao thức deterministic.            |

## Chạy một ví dụ

```sh
zig build hello_world -Doptimize=ReleaseSafe
./zig-out/bin/hello_world
```

Trong terminal khác:

```sh
curl -i http://127.0.0.1:3000/
```

Phản hồi là `HTTP/1.1 200 OK` với body từ `examples/hello_world.zig`. Dùng cùng
cách cho mọi bước: build bước, chạy binary và gửi request được hiển thị trên
trang site của nó.

## Port tổng hợp

| Port |         Giao thức | Ví dụ                                                                                      |
| ---- | ----------------: | ------------------------------------------------------------------------------------------ |
| 3000 |          HTTP/1.1 | `hello_world`, `chat_server`, `rpc_server`, `shared_nothing_cluster`, `basic_microservice` |
| 3001 |          HTTP/1.1 | `custom_builder`                                                                           |
| 3443 |             HTTPS | `https_server`                                                                             |
| 8000 |          HTTP/1.1 | `h1spec`                                                                                   |
| 8443 | HTTPS hoặc HTTP/3 | `tls_cluster`, `http3_server`                                                              |
| 9001 |         WebSocket | `autobahn_server`                                                                          |

Chỉ một process bind được một port tại một thời điểm. Dừng ví dụ trước trước
khi chạy ví dụ khác trên cùng port.
