Helper là các utility nhỏ, ghép được trong `uz` và không sở hữu protocol nào.
Chúng parse dữ liệu request mang tới, giữ state có giới hạn quanh một response,
biến đổi byte bạn đã tạo, hoặc adapter một transport khác thành stream kiểu
pull.

Ở thời điểm request, mọi helper mượn từ buffer có giới hạn, ghi vào vùng nhớ của
caller, hoặc trả về view cố định lúc compile. HTTP gzip pool cấp phát lúc
application init. `CompressionStream` hoặc `DecompressionStream` cấp phát codec
trong `init`, nên coi `init` đó là allocation tường minh, không phải chi phí ẩn
trên request path.

## Trang lõi không phải helper

Các trang này thuộc application surface của HTTP, không thuộc nhóm helper.
Bắt đầu ở đây khi tác vụ là một field của request, một response mode hoặc một
quy tắc wire.

| Trang                                               | Đọc để                                             |
| --------------------------------------------------- | -------------------------------------------------- |
| [API request](/docs/http/request)                   | Method, target, header, body và route capture      |
| [API response](/docs/http/response)                 | Status, header, text, byte và trạng thái response  |
| [JSON response](/docs/http/json)                    | `res.json`, `res.json_buf` và `begin_json`         |
| [Streaming response](/docs/http/streaming)          | `begin_stream` và `StreamProducer` chạy theo drain |
| [Server-Sent Events](/docs/http/server-sent-events) | Event framing, heartbeat và `res.sse()`            |
| [HTTP error](/docs/http/errors)                     | Tài liệu rejection có cấu trúc và status helper    |
| [Static file](/docs/http/static-files)              | Mount, confinement, validator và byte range        |

## Ranh giới

Helper không quyết định byte đi ra wire như thế nào. Parse HTTP/1.1, response
framing, chunked transfer và keep-alive thuộc về
[HTTP/1.1 và application API](/docs/http). Handshake, framing, masking và
compression của WebSocket nằm trong tài liệu protocol tại `docs/websocket.md`.

Những phần sau cố ý nằm ngoài nhóm này:

- CORS, authentication, rate limiting và security header. Đây là security
  control, được ghi trong [middleware](/docs/http/middleware).
- JSON, streaming, SSE, chunked output, static file và OpenAPI. Đây là các
  response mode lõi của mục HTTP.
- `uz.schema` và typed RPC. Đây là tính năng type safety, không phải utility.
