Phần khái niệm giải thích cách một giá trị application trở thành hành vi runtime có
giới hạn. Hãy đọc phần này trước các trang giao thức. Mỗi trang giao thức liên kết
ngược về đây thay vì lặp lại mô hình.

Sáu trang đầu bao phủ các phần của đường đi request: dựng application, parse
request, hoàn tất response, match route, dạng handler và middleware. Các trang
sau nói về bộ nhớ, concurrency và ranh giới lỗi phía sau đường đi đó.

## Bắt đầu từ đâu

Nếu bạn đang chọn giới hạn, đọc [Mô hình application](/docs/concepts/application-model)
và [Mô hình capacity](/docs/concepts/capacity-model) trước. Nếu bạn đang viết
handler, đọc [Vòng đời request](/docs/concepts/request-lifecycle) và
[Dạng handler](/docs/concepts/handler-shapes). Nếu bạn đang thêm policy áp dụng
cho nhiều route, đọc [Mô hình middleware](/docs/concepts/middleware-model).
