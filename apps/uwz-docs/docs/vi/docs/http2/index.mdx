Mỗi TCP connection mang một HTTP/2 server session tùy chọn. Request decode từ
HTTP/2 đi qua cùng router, middleware, handler và response helper như HTTP/1.1,
nên route viết cho transport này chạy được trên transport kia. Khác biệt nằm ở
wire: stream, HPACK header block và flow-control window.

Session được giới hạn có chủ đích. Nó xử lý request/response routing tốt và không
nhắm tới full RFC 9113 feature parity. [HTTPS server example](/examples/https-server)
cho thấy ALPN path trên một application.

## Đường khởi động

| Đường     | Cơ chế                                                                               |
| --------- | ------------------------------------------------------------------------------------ |
| TLS       | ALPN chọn `h2` trước `http/1.1` trên `init_https` và `init_https_ephemeral`          |
| Plaintext | Prior knowledge: client mở bằng HTTP/2 preface được phát hiện trước HTTP/1.1 parsing |
| Upgrade   | Không hỗ trợ; h2c Upgrade không có                                                   |

Cleartext prior knowledge nghĩa là client gửi
`PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n` như byte đầu tiên. HTTP/1.1 request bình
thường trên cùng listener được parse như HTTP/1.1.

## Session triển khai gì

- Validation nghiêm cho preface, frame size và frame sequence.
- SETTINGS negotiation, PING, GOAWAY và RST_STREAM.
- Stream identifier, gồm quy tắc closed-stream của RFC 9113.
- HEADERS với CONTINUATION, DATA, trailer và padding.
- HPACK với dynamic table có giới hạn.
- Flow control cấp connection và cấp stream.
- Async response token và producer điều khiển bởi drain.
- RFC 8441 extended CONNECT cho WebSocket.

## Ranh giới

| Tính năng                   | Trạng thái                        |
| --------------------------- | --------------------------------- |
| Stream đồng thời            | 8 mỗi connection                  |
| Server push                 | Không hỗ trợ                      |
| h2c Upgrade                 | Không hỗ trợ; chỉ prior knowledge |
| Nhiều hơn 8 stream          | Cần specialize connection type    |
| WebSocket tunnel            | 1 mỗi connection, không nén       |
| HTTP/2 cleartext có Upgrade | Không triển khai                  |

:::warning[Routing, không phải full parity]
"HTTP/2 chạy" trên site này nghĩa là request route, stream và response qua
application boundary dùng chung. Nó không có nghĩa mọi extension, prioritization
hay push mechanism của RFC 9113 đều được triển khai.
:::
