Trang này là support contract cho µWebZockets 2.1.6. Nó nêu compiler, platform,
revision của dependency, hình thức release, C ABI version và TLS policy mà phần
còn lại của site dựa vào. Khi một support claim thay đổi, trang này thay đổi
trong cùng release.

## Tóm nhanh [#at-a-glance]

| Mục                  | Giá trị                                                                |
| -------------------- | ---------------------------------------------------------------------- |
| Release              | 2.1.6, phát hành 2026-10-26                                            |
| Zig                  | Chỉ 0.16.0                                                             |
| C ABI                | Version 1.0, layout 1.x frozen                                         |
| TLS                  | Chỉ TLS 1.3                                                            |
| Platform được hỗ trợ | Linux và macOS trên `x86_64` và `aarch64`                              |
| Release artifact     | Git source tag; không có binary archive                                |
| Security support     | Development revision hiện tại và minor line đã release gần nhất, 2.1.x |

## Zig và toolchain [#zig-and-toolchain]

Package manifest khai báo `minimum_zig_version = "0.16.0"`, và roadmap gọi Zig
0.16.0 là toolchain duy nhất được hỗ trợ. Hãy coi compiler mới hơn là chưa được
test dù field manifest là minimum. Nix flake pin Nixpkgs 26.05 và cung cấp
toolchain được hỗ trợ.

Zig fetch và compile mọi native dependency. Bạn không cần CMake, Ninja, Go, Perl,
Python, `patch` hay zlib cài trên hệ thống. Lần build đầu tải các package đã pin
vào Zig cache; các lần sau dùng lại cache.

## Nền tảng hỗ trợ [#platform-support]

| Platform                               | Build target         | Runtime CI                                                     | Support claim                                               | Caveat                                                                       |
| -------------------------------------- | -------------------- | -------------------------------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Linux `x86_64` và `aarch64`            | Native               | Hosted runtime và sanitizer matrix                             | Supported                                                   | Sanitizer build chỉ trên native Linux                                        |
| macOS `x86_64` và `aarch64`            | Native và cross      | Không có hosted kqueue job; test graph cross-compile khi cần   | Supported                                                   | Cluster worker không pin vì macOS không có hard-affinity API                 |
| Windows `x86_64`                       | `x86_64-windows-gnu` | Job runtime `windows-2025` cùng compile và ReleaseFast library | Platform-gated cho tới khi job chạy xanh cho release commit | Không có Windows binary; ADR 0004 sở hữu hành vi IOCP accept và queued close |
| FreeBSD, NetBSD, OpenBSD, DragonFlyBSD | Build graph chung    | Không có                                                       | Community builds                                            | Compile được nhưng không chạy trong CI                                       |

Linux là platform có runtime và sanitizer matrix hosted đầy đủ. macOS được hỗ
trợ, nhưng kqueue coverage là evidence đã ghi chứ không phải hosted job. Hỗ trợ
chính thức cho Windows chỉ bắt đầu khi native runtime job xanh cho release
commit; trước đó compile gate là claim. Bốn BSD target dùng chung build graph và
không có runtime CI riêng, nên deployment trên BSD là bản build cộng đồng và
evidence thuộc về người deploy.

Shared-nothing clustering được hỗ trợ đầy đủ trên Linux. macOS chạy worker không
pin. Windows dùng fallback `SO_REUSEADDR` và không bảo đảm worker-to-core
affinity. Chi tiết framework nằm trong
[Nền tảng hỗ trợ](/docs/operations/platforms).

## Dependency pin [#dependency-pins]

Mỗi entry mang một URL hoặc commit immutable và một Zig package hash. Archive
hoặc commit bị đổi sẽ làm dependency resolution fail thay vì âm thầm thay source
đã review. Các maintained fork pin full 40-hex commit.

| Dependency | Source                   | Pin                                                                                                                                         | Vai trò                                     |
| ---------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| zslay      | `farbenbuilds/zslay`     | Archive `v0.2.1`                                                                                                                            | WebSocket frame state machine               |
| libxev     | `farbenbuilds/libxev`    | `c49f6dfb83038c146232472c063e4b2681d098d8` trên `uwz/zig-0.16`; base `9ce8e8e6ff89e583258a7f8e7adeeeaeae8611bf` cộng XEV-001 đến XEV-005    | Event loop và completion                    |
| BoringSSL  | `google/boringssl`       | `d3bf4795ad5b79d646cddf2fec687da5b9b502db`, release 0.20261020.0                                                                            | TLS 1.3, ALPN và crypto primitive           |
| lsquic     | `farbenbuilds/lsquic`    | `85bd081c9103c077a7cc98271d09334d0f1043d4` trên `uwz/main`; base v4.10.2 `a9616720af78b9aab895145c1792d5305c480ae8` cộng LSQ-001 và LSQ-002 | QUIC và HTTP/3 engine                       |
| ls-qpack   | `litespeedtech/ls-qpack` | `91567706c41c0d97ab8dc576873ecd472d7869fa`                                                                                                  | QPACK header compression                    |
| ls-hpack   | `litespeedtech/ls-hpack` | `fda48e02491d865cce00612be8cc10c2622b8e55`                                                                                                  | HPACK support dùng bởi lsquic               |
| libdeflate | `ebiggers/libdeflate`    | `92e6a0db9fa848d742f9eb286c92afc60f2c3dda`                                                                                                  | Codec RFC 7692 và HTTP gzip                 |
| zlib       | `madler/zlib`            | Archive `v1.3.2`                                                                                                                            | Compression compatibility và static archive |

Pin policy, fork ledger và hành vi lần build đầu nằm trong
[Chính sách dependency](/docs/architecture/dependencies). Submodule `h1spec` chỉ
là input cho development và không cần cho một package dependency.

## Release policy [#release-policy]

| Policy              | Giá trị                                                                              |
| ------------------- | ------------------------------------------------------------------------------------ |
| Version scheme      | Semantic Versioning, ghi trong `CHANGELOG.md`                                        |
| Release hiện tại    | 2.1.6, 2026-10-26                                                                    |
| Artifact            | Git source tag                                                                       |
| Binary archive      | Không có, cho mọi platform                                                           |
| Fetch               | `zig fetch --save 'git+https://github.com/farbenbuilds/uWebZockets#<tag-or-commit>'` |
| Security support    | Development revision hiện tại và minor line đã release gần nhất, 2.1.x               |
| Release cũ          | Không backport cho tagged release cũ hoặc snapshot trước đó                          |
| C ABI compatibility | Layout 1.x frozen; enum addition append-only                                         |
| Unreleased tree     | Có thể chứa thay đổi chưa release; pin tag hoặc full commit                          |

2.1.6 là patch release. Nó không thay đổi public API, C ABI layout, capacity, wire
format hay TLS policy. Sau một release, tree có thể chứa thay đổi chưa release;
tag, không phải branch, là đơn vị compatible.

Release là source tag, không có binary archive. Consumer fetch tag và để Zig
build dependency đã pin cho target của mình. Không có binary Windows, macOS hay
Linux để tải và kiểm tra.

## C ABI version [#c-abi-version]

| Mục           | Giá trị                                                       |
| ------------- | ------------------------------------------------------------- |
| Header        | `include/uWebZockets.h`                                       |
| ABI version   | 1.0                                                           |
| Version macro | `UWZ_VERSION_MAJOR`, `UWZ_VERSION_MINOR`, `UWZ_VERSION_PATCH` |
| Layout rule   | Field order, field type và size frozen cho ABI 1.x            |
| Enum rule     | Value mới được append; value cũ không bị đánh số lại          |
| Scope         | Chỉ high-level server operation                               |

ABI dùng opaque handle, `uwz_slice` byte view và `uwz_error`. Nó cố định 1.024
connection slot, 64 route, 32 middleware entry, 16 inline route parameter và
route path 2.048 byte. Các module low-level HTTP/2, HPACK, HTTP/3-extension,
WebTransport, UDP và client vẫn chỉ có Zig.

Xem [C ABI](/reference/c-abi) cho toàn bộ surface và
[Nhúng từ C hoặc C++](/docs/guides/c-abi) cho build recipe của consumer.

## TLS policy [#tls-policy]

| Policy       | Giá trị                                                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Protocol     | Chỉ TLS 1.3; TLS 1.2 và cũ hơn bị từ chối                                                                                                  |
| ALPN         | `h2` rồi `http/1.1` trên TCP; chỉ `h3` trên QUIC                                                                                           |
| Certificate  | PEM chain và key, hoặc ephemeral certificate trong memory cho development                                                                  |
| mTLS         | `none`, `optional` hoặc `required`; chỉ TCP; `required` fail handshake closed                                                              |
| 0-RTT        | TCP nhận `GET`, `HEAD`, `OPTIONS` và `TRACE`; method khác nhận `425 Too Early`; `QUERY` replay-unsafe; live HTTP/3 listener tắt early data |
| Rotation     | Rolling restart; không hot certificate reload                                                                                              |
| Cluster TLS  | Một `SSL_CTX` mỗi worker; ticket state theo worker                                                                                         |
| Client trust | Không có trust store đi kèm; `ca_path` bắt buộc khi `verify = true`; `verify = false` chỉ development                                      |

TLS-enabled cluster dùng cùng TLS 1.3 và ALPN policy như single application.
Client-certificate mode tắt early data vì client certificate được kiểm tra ở
flight thứ hai. Client pin TLS 1.3 làm cả minimum và maximum version và không
xuất trình client certificate.

## Browser và protocol client compatibility [#browser-and-client-compatibility]

| Client            | Đi tới                       | Ràng buộc                                                                       |
| ----------------- | ---------------------------- | ------------------------------------------------------------------------------- |
| Browser, HTTP/1.1 | HTTP/1.1 trên TCP hoặc TLS   | `fetch`, XHR và navigation tiêu chuẩn                                           |
| Browser, HTTP/2   | HTTP/2 trên TLS qua ALPN     | Browser gửi `h2` trong ALPN; server ưu tiên nó hơn `http/1.1`                   |
| Browser, HTTP/3   | HTTP/3 trên QUIC             | Cần h3 support, đường UDP tới được và certificate được tin cậy                  |
| Browser WebSocket | RFC 6455 trên HTTP/1.1       | WebSocket API tiêu chuẩn                                                        |
| Browser RFC 8441  | WebSocket trên HTTP/2        | Cần client hỗ trợ extended CONNECT; một tunnel mỗi connection                   |
| curl              | HTTP/1.1, HTTP/2 hoặc HTTP/3 | Dùng `--http2` hoặc `--http3-only`; `-k` chỉ cho ephemeral certificate          |
| h2load            | HTTP/2                       | Dùng bản nghttp2 hiện hành; benchmark harness yêu cầu 1.69.0 trở lên            |
| wscat             | WebSocket                    | Kiểm tra handshake và message                                                   |
| `uz.client`       | HTTP/1.1 trên TCP hoặc TLS   | Chỉ numeric host; không redirect, cookie, proxy, retry, mTLS, HTTP/2 hay HTTP/3 |

Cleartext HTTP/2 chỉ prior knowledge. Browser dùng TLS ALPN; prior knowledge path
dành cho tool và service client. Dòng client compatibility mô tả outbound client
đi kèm, không phải claim rằng µWebZockets ship browser client hay HTTP/2 client.

## Những gì compatibility không bảo đảm [#what-compatibility-does-not-promise]

- Không có runtime guarantee cho Windows trước khi release job chạy xanh, hoặc
  cho bất kỳ BSD target nào.
- Không có binary artifact cho bất kỳ platform nào.
- Không có TLS 1.2 fallback hoặc protocol range cấu hình được.
- Không có dynamic capacity vượt fixed startup slab.
- Không có HTTP/2 hoặc HTTP/3 client trong `uz.client`.
