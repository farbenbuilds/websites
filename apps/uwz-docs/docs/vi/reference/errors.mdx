Dùng trang này để xác định một lỗi Zig, JSON-RPC fault, WebSocket rejection hoặc
C ABI code. [Errors and failure modes](/docs/concepts/errors) giải thích hai kênh
báo lỗi; [HTTP errors](/docs/http/errors) trình bày response document. Các bảng
dưới đây là nơi tra cứu tên lỗi và nguyên nhân.

## How to read an error [#how-to-read-an-error]

Lỗi Zig là một giá trị trong error union. Nó mang một tên ổn định, không phải
message đã format, và `@errorName` trả về tên đó. Lỗi startup và registration
xảy ra trước khi có request, nên không có HTTP status. Lỗi lúc request sẽ trở
thành response status, WebSocket close code hoặc transport abort do đoạn code
bắt lỗi quyết định.

```zig
const std = @import("std");
const uz = @import("uWebZockets");

fn hello(_: *uz.Request, res: *uz.Response) void {
    res.text("ok") catch |err| {
        std.debug.print("response: {s}\n", .{@errorName(err)});
    };
}

pub fn main(init: std.process.Init) !void {
    var app = try uz.App(128).init(init.io);
    defer app.deinit();

    _ = app.get("/", hello) catch |err| {
        std.debug.print("route registration: {s}\n", .{@errorName(err)});
        return err;
    };
    try app.listen("0.0.0.0", 3000);
    try app.run();
}
```

| Form                         | Meaning                                    |
| ---------------------------- | ------------------------------------------ |
| `error.RouteCapacityReached` | Error tag Zig mà một call trả về           |
| `@errorName(err)`            | Tag dưới dạng string, dùng cho log và test |
| `uwz_error_name(code)`       | Tên C ABI tĩnh, gồm cả `unknown error`     |
| `4xx` hoặc `5xx`             | Status dành cho peer, không phải error tag |

Dùng `switch` để so khớp giá trị lỗi; không parse log line hay status string để
lấy lại tên. Một lỗi terminal cần đổi cấu hình hoặc code, không phải vòng retry.

mount. Capacity mặc định là `256` node, `64` pattern route, `32` middleware
callback, `2 KiB` mỗi path và `64 KiB` cho route registry.

| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `error.InvalidRoutePath`              | Rỗng, không bắt đầu bằng `/`, dài hơn `max_route_path_size`, hoặc chứa `?`, `#`, CR hay LF. | `error.InvalidRoutePattern`           | Tên capture rỗng hoặc ngoài `[A-Za-z0-9_-]`, wildcard không phải segment cuối, hoặc hai capture trùng tên                                                                                      | Không có, registration | Đặt tên mỗi capture một lần và chỉ kết thúc bằng `*` ở cuối path                                | `src/router/radix_pattern.zig`                       |
| `error.RouteCapacityReached`          | Không còn radix node, pattern slot hoặc route record                                                                                                                                           | Không có, registration | Đơn giản hóa shared prefix, hoặc tăng `max_route_nodes` và `max_pattern_routes`                 | `src/router/radix.zig`                               |

`426 Upgrade Required`. Route `upgrade` callback trả `false` sẽ gửi
`403 Forbidden` mà không đặt error name.

| Zig error name                   | Cause                                              | HTTP status | Fix                                       | Source module          |
| -------------------------------- | -------------------------------------------------- | ----------- | ----------------------------------------- | ---------------------- |

| `error.MissingConnectionUpgrade` | `Connection` không có hoặc thiếu token `upgrade`   | `400`       | Gửi `Connection: Upgrade`                 | `src/ws/handshake.zig` |
| `error.MissingUpgradeWebSocket`  | `Upgrade` không có hoặc không phải `websocket`     | `400`       | Gửi `Upgrade: websocket`                  | `src/ws/handshake.zig` |
| `error.MissingVersion`           | `Sec-WebSocket-Version` không có hoặc bị duplicate | `426`       | Gửi một field `Sec-WebSocket-Version: 13` | `src/ws/handshake.zig` |
| `error.UnsupportedVersion`       | Version không phải `13`                            | `426`       | Dùng RFC 6455 version `13`                | `src/ws/handshake.zig` |
| `error.MissingKey`               | `Sec-WebSocket-Key` không có hoặc bị duplicate     | `400`       | Gửi một key field                         | `src/ws/handshake.zig` |
| `error.InvalidKey`               | Key không phải base64 canonical cho 16 byte        | `400`       | Gửi key base64 16 byte mới                | `src/ws/handshake.zig` |

`handshake.validate_extended_connect` dùng lại `error.MissingVersion` và
`error.UnsupportedVersion` cho RFC 8441. Caller chọn rejection; helper không ghi
response.

## C ABI codes [#c-abi-codes]

Các giá trị âm là append-only và thuộc ABI.

`unknown error` ngoài enum.

|  Code | Constant                     | Name string        | Reported when                                                                      |
| ----: | ---------------------------- | ------------------ | ---------------------------------------------------------------------------------- |
|   `0` | `UWZ_OK`                     | `ok`               | Call hoàn tất                                                                      |
|  `-1` | `UWZ_ERROR_INVALID_ARGUMENT` | `invalid argument` | Slice sai, out-handle đã chiếm, route không hợp lệ, method hoặc limit không hợp lệ |
|  `-2` | `UWZ_ERROR_OUT_OF_MEMORY`    | `out of memory`    | Slab, TLS context hoặc QUIC engine allocation fail                                 |
|  `-3` | `UWZ_ERROR_INVALID_STATE`    | `invalid state`    | Sai lifecycle step, response đã start, token cũ, HTTP/3 chưa init                  |
|  `-4` | `UWZ_ERROR_ALREADY_EXISTS`   | `already exists`   | Route pattern trùng hoặc listener đã bind                                          |
|  `-5` | `UWZ_ERROR_CAPACITY`         | `capacity reached` | Route, middleware, parameter, storage hoặc peer capacity đã đạt giới hạn           |
|  `-6` | `UWZ_ERROR_WOULD_BLOCK`      | `would block`      | Output queue hoặc write path đầy                                                   |
|  `-7` | `UWZ_ERROR_PROTOCOL`         | `protocol error`   | Framing, handshake hoặc output quá lớn                                             |
|  `-8` | `UWZ_ERROR_IO`               | `I/O error`        | Socket, bind hoặc TLS read và write fail                                           |
|  `-9` | `UWZ_ERROR_UNSUPPORTED`      | `unsupported`      | HTTP/3 không có, hoặc backend không có                                             |
| `-10` | `UWZ_ERROR_INTERNAL`         | `internal error`   | Lỗi không có mapping hẹp hơn                                                       |
