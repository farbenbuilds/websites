Hướng dẫn này đưa bạn từ một checkout mới đến một máy chủ đang chạy. Giả định dùng Zig 0.16.0.

## Thử máy chủ ví dụ [#try-the-example-server]

Khi đã cài Nix, cách ngắn nhất là:

```sh
git clone https://github.com/farbenbuilds/uWebZockets.git
cd uWebZockets
nix develop
zig build hello_world -Doptimize=ReleaseSafe
```

Ở terminal khác:

```sh
curl -i http://127.0.0.1:3000/
```

Lần build đầu tiên tải các dependency được ghim (BoringSSL, lsquic, libxev, zslay, libdeflate, zlib) qua trình quản lý gói của Zig và biên dịch chúng bằng bộ công cụ C/C++ của Zig — không cần CMake, Ninja, Go, Perl, Python hay zlib của hệ thống. Các lần build sau dùng lại cache.

## Dùng trong dự án của bạn [#use-it-in-your-own-project]

µWebZockets là một gói Zig. Hãy fetch một tag phát hành hoặc một commit đầy đủ để việc phân giải dependency luôn tái lập được:

```sh
zig fetch --save 'git+https://github.com/farbenbuilds/uWebZockets#<tag-or-commit>'
```

Khai báo dependency trong `build.zig`:

```zig
const uz = b.dependency("uWebZockets", .{
    .target = target,
    .optimize = optimize,
});
exe.root_module.addImport("uWebZockets", uz.module("uWebZockets"));
```

Sau đó, một máy chủ hoàn chỉnh chỉ cần vài dòng:

```zig
const std = @import("std");
const uz = @import("uWebZockets");

fn hello(_: *uz.Request, res: *uz.Response) void {
    res.text("hello from a dependency") catch {};
}

pub fn main(init: std.process.Init) !void {
    var app = try uz.App(128).init(init.io);
    defer app.deinit();

    _ = try app.get("/", hello);
    try app.listen("0.0.0.0", 3000);
    try app.run();
}
```

`zig build run` khởi chạy nó, và `curl http://127.0.0.1:3000/` in ra body.
