# Butterfly specimen images

These are 96px-wide pixel derivatives of public-domain butterfly specimens from
Wikimedia Commons. They are drawn at larger sizes with nearest-neighbour scaling
for the pixelated hero.

| File               | Source                                                                       |
| ------------------ | ---------------------------------------------------------------------------- |
| `monarch.png`      | https://commons.wikimedia.org/wiki/File:Danaus_plexippus-transparent.png     |
| `painted-lady.png` | https://commons.wikimedia.org/wiki/File:Vanessa_virginiensis-transparent.png |
| `sulphur.png`      | https://commons.wikimedia.org/wiki/File:Colias_eurytheme-transparent.png     |

License: Public domain, as recorded on each Commons file page. The local change
is a 96px width downscale with `ffmpeg`; the transparent background is retained.
